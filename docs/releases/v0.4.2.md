# car-go-clean v0.4.2

## Fix

- The macOS default discovery exclusions now skip the standard
  `Photos Library.photoslibrary` bundle wherever it appears. This prevents
  privacy protection from making a first whole-home scan incomplete without
  changing Linux discovery defaults or depending on a fixed home-directory
  layout.

## Upgrade

For a normal same-line update, stop an active daemon, upgrade with the method
that owns `car-go-clean`, then generate a fresh dry-run review before cleaning.
For a v0.2/v0.3-to-v0.4 migration, use the
[legacy upgrade guide](../upgrading-v0.2-v0.3.md).
