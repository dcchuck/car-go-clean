# car-go-clean v0.4.1

## Fix

- Excluded stale Git-worktree discovery failures and their linked-worktree
  provenance are now reconciled before a review, including deleted paths below
  protected roots such as OrbStack.
- Existing failures for live paths, missing primaries with live linked
  worktrees, and legacy failures without a trusted canonical path remain
  fail-closed.

This fixes a regression where deleted container worktrees could make every
cached Cargo project appear as `scan_error`, causing a successful run to
reclaim zero bytes.

## Upgrade

For a normal same-line update, stop an active daemon, upgrade with the method
that owns `car-go-clean`, then generate a fresh dry-run review before cleaning.
The v0.2/v0.3-to-v0.4 migration helper remains the supported path for those
older installations.
